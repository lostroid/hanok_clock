* HANOK CLOCK은 한옥 모양의 탁상용 시계 프로젝트입니다.
* 개발 방향: 주요 인터페이스 학습, 무선 기능 개발, Bare Metal 시스템 개발

### 1차 목표

1. 시계 기능: 년·월·일(요일)·시·분·초 정보 제공
2. 이벤트 알람 기능: 지정한 날짜·시간에 알람
3. 블루투스 스피커 기능: 휴대폰과 Bluetooth로 연결해 음악 재생
4. 앨범 기능: BMP 형식 이미지를 화면에 표시 (전환 간격 1초~1000초 조정)
5. 온도 표시 기능 (온습도 센서, I2C)
6. 습도 표시 기능
7. 광 센서 기능: 광 센서로 디스플레이 밝기 자동 조절
